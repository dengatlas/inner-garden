# Inner Garden · 美日心灵 1.3.4

修复桌面 flomo 在上传中断后重试时可能显示 `Operation ID reused` 的问题。Chrome 读回待上传数据时可能调整 JSON 字段顺序，导致内容相同的重试被云端判为不同的上传请求。新版固定上传文本的字段顺序，并尝试继续旧版尚未确认的上传。

## 安装与更新

- 安装附件为 `inner-garden-1.3.4.zip`，可用同名 `.sha256` 文件核对。首次安装时解压 ZIP，在 `chrome://extensions` 启用开发者模式，加载包含 `manifest.json` 的目录。
- 已安装公开版时，将新文件覆盖到原安装目录，点击扩展的“重新加载”，再打开新标签页。沿用原扩展条目和浏览器个人资料可保留本机内容和待同步队列。
- 此前遇到该报错时，更新后在桌面点“立即同步”。逐条笔记和标签的冲突选择继续按现有规则处理。此次修复适用于桌面插件，沿用现有云端接口和小程序。

详细步骤见 [安装说明](INSTALL.md)，测试范围见 [验收记录](ACCEPTANCE.md)。
