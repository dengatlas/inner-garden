# 数据与隐私说明

核心内容保存在当前 Chrome 个人资料的 `chrome.storage.local`。部分视图偏好和草稿也使用 localStorage、sessionStorage。程序目录不包含浏览器中的个人内容；复制源码不迁移登录状态。

## 本机保存

浏览器标签信息用于分组、去重、切换和关闭。稍后再看、专注状态保存在本机。工作区包括日历、周计划、日课、账号工作区快照和恢复备份。未登录也可以编辑；网络失败不会把已有内容从本机删除。

flomo 使用独立笔记库。图片、草稿和视图偏好留在本机。导出文件和设备迁移包含用户内容，由用户自行保存；发布包不附带这些文件。

## 可选账号同步

本版预配置现有 CloudBase 服务。登录、注册或验证码等账号操作会按用户操作访问认证服务；实际是否可注册及哪些账号被允许，由该服务端规则决定。工作区同步只包含日历事件、周计划项和日课字段。标签、稍后再看、专注状态不进入工作区同步。

flomo 首次同步需单独开启，之后账号手动／自动同步一起调度，分别报告结果；交换文字、标签、置顶、回收站与删除标记，图片不会上传。账号内容按当前账号隔离，不自动合并不同账号。自动同步间隔固定为 12 分钟，手动同步可立即触发。

认证会话保存在本机，设备迁移包排除对应会话键。同步使用 HTTPS，但不是端到端加密；服务运营方可接触其管理范围内的同步明文。连接地址和环境 ID 是服务标识，不是管理员密钥。

手机授权电脑采用短时 OAuth device flow。二维码在本机生成，仅包含协议、环境标识及授权编号；不含手机 Token、电脑 device_code 或笔记。手机确认时使用当前会话调用 CloudBase；电脑取得独立会话后先显示 UID，待用户核对确认才保存登录会话。关闭、过期或重新生成后的旧结果不能写入当前账号。登录确认触发日程同步，flomo 需另行开启。

## 网络资源

页面字体随包提供，网站图标在本地生成；不会为它们请求 Google Fonts 或 Google favicon。用户主动点击网页链接仍由浏览器打开对应网站。默认认证、工作区、flomo 请求使用 `dk-checkin-d8gw6jhrt5b2ced62-1467421685.ap-shanghai.app.tcloudbase.com`。

## Chrome 权限

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取标签标题和 URL、分组、去重、跨窗口切换及关闭 |
| `activeTab` | 保留现有用户触发的标签操作权限；无内容脚本注入 |
| `storage` | 保存本机内容、账号状态和备份 |
| `unlimitedStorage` | 为本机笔记图片和恢复数据保留存储空间 |
| 可选 CloudBase 域名权限 | 用户允许后访问账号与同步服务 |

## 删除与备份

卸载扩展会移除其 Chrome 本机存储；停用不会等于卸载。卸载不自动删除云端账号或云端内容。更换个人资料或扩展 ID 会使用另一份本机存储。先备份再迁移；工作区与 flomo 的导出范围不同。
