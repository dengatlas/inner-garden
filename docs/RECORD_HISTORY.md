# 记录恢复、同步与版本历史

## 当前状态

桌面版本为 1.3.3，1.3.2 ZIP 与校验文件保留。现有工作区历史服务已于 2026-11-01 上线并通过独立测试账号的真实数据库事务验收；小程序已有预览，尚未在本轮正式发布。桌面发布、个人终端安装和三端真实操作分别验收。

2026-11-01 的只读排查发现，一条经用户确认属于当天的时间块在上传前已保存为前一天。已先保存排除凭据的本机私有备份，通过扩展后台更正原记录日期并同步；Chrome 与 Ego 的本机数据均核对到更正后的日期，当天已有日课字段保留。该证据不代表其他可能缺失的文字均已恢复。两次原始同步的四项云端变更均为新增，没有删除操作；日期误存的具体操作路径尚未重现，不能归因于时区转换或整日同步删除。

## 数据规则

- 日程按 ID、日课按日期及字段、周计划按条目 ID 合并；不同 ID 的新增取并集，重叠时间块不自动去重。
- 当前客户端启用明确删除模式，缺失快照不生成删除。手机编辑器基于最新工作区保存本条变化；旧编辑器不能复活已下载的删除。
- 同条过期写入使用有效编辑时间决定新版，上传顺序不作为编辑先后；异常时钟仍保留显式冲突。云端墓碑阻止旧基线重发复活记录。
- 每个浏览器/手机生成独立的 workspace 设备身份，重启保留、迁移排除。已经发送的队列及其 deviceId/opId/payload 不重写，原专注记录来源不改写。
- 所有记录日期与显示使用 Asia/Shanghai，系统城市和夏令时不自动移动记录。
- 草稿、图片、偏好留在本机。未同步的中间编辑不能冒充已存于云端的历史。

## 查看与恢复

已有时间块与日课编辑器可进入“历史”；日历/日课日期旁的“更多 → 当天变更”可查找移日期和删除记录。桌面宽屏为左侧版本列表及右侧比较，窄屏上下显示；小程序共用全屏历史页。日期、时间、标题、颜色和正文分开比较，支持只看变化、全文、复制。

历史由账号隔离的 workspace_record_history 保存当前值及最近两个不同旧内容，没有 TTL。重复请求与相同内容不占旧版名额，已有 sync_changes 可惰性回填。丢失回执重试保留操作标识；旧收据不能把后来下载的新版本回退。历史列表分页绑定账号、日期及变更 generation，失效后原地刷新。

恢复需要联网，并校验预览时的当前版本；成功产生新版本，原当前内容转为历史。若本条尚有待同步的已保存操作，先同步再重新比较，避免丢弃待确认请求。未提交编辑先保留为账号及记录隔离的本机草稿。恢复广播只替换目标实体，各页面先保留旧草稿、停止关联旧生成稿回写，再刷新对应编辑框；重复广播和响应不重复覆盖新编辑。

离线仅显示已缓存历史并允许复制，明确标记缓存时间。账号鉴权失败不能伪装成离线缓存成功，账号切换立即隐藏旧账号历史。接口未部署时显示服务尚未开放，不改变本机内容。

## 服务端与上线

现有 POST /history、/history/changes、/history/restore 的新实现只接受日程和日课类型。身份由现有鉴权上下文提供，历史 ID、账号、恢复前版本和幂等请求均校验。集合、历史写入、当前记录、变更流水及收据在同一事务提交。

云端准备、三个复合索引、ADMINONLY 权限、迁移备份范围和仅更新 tab-out-sync 的步骤见 D:/tab-out/backend/cloudbase-sync/RECORD_HISTORY.md。不修改来源、认证设置、网关路由或微信合法域名；不部署旧桌面、PWA、flomo 或其他后端。
