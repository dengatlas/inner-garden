# 安装、更新与迁移

这是桌面 Chrome Manifest V3 新标签页扩展。安装不需要 Node、npm、后端部署或编译源码。

## 获取安装包

从 [v1.3.3 发布页](https://github.com/dengatlas/inner-garden/releases/tag/v1.3.3)下载 `inner-garden-1.3.3.zip`，可同时下载 `.sha256` 文件核对 SHA-256。请区分发布附件与 GitHub 自动生成的源码 ZIP；两者加载目录见下文。以下步骤按 Windows Chrome 说明，不需要运行命令或自行部署服务。

## 从安装包安装

1. 解压 `inner-garden-1.3.3.zip` 到准备长期保留的文件夹。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
4. 打开新标签页。未登录也可以编辑本机工作区和笔记。

从源码目录安装时，应选择 `extension/` 子目录。不要双击 HTML，也不要把 GitHub Pages 当成扩展安装方式。下载 ZIP 后需要解压；不承诺普通 Windows/macOS Chrome 可以任意拖拽 CRX 安装。

## 从公开仓库安装

访问 [dengatlas/inner-garden](https://github.com/dengatlas/inner-garden)，点击 **Code → Download ZIP**，解压后按上面的 Chrome 操作加载其中的 `extension/` 目录。源码 ZIP 包含可直接运行的扩展文件，无需执行构建命令。它与本地生成的安装 ZIP 目录结构不同：源码 ZIP 的 `manifest.json` 位于 `extension/` 子目录。

## 本机内容迁移

在旧扩展的选项页“设备迁移”导出迁移包，再在新版的选项页导入。迁移包含用户内容，应保存在自己的设备上；不要提交到仓库或作为公开示例。

导入只接受尚未保存用户内容、未登录的空白安装。初始化产生的空工作区不应阻止导入；已经写入的事件、日课、笔记、草稿或账号会话会阻止导入。不要先卸载旧版。导入后重新打开新版新标签页，并使用原账号重新登录。此路径继续使用相同云环境，不移植跨服务账号。

迁移包排除认证会话并清空设备 ID。工作区 JSON、Markdown 和 flomo 导出各有不同范围，单次周计划导出不是全部设备数据的备份。

## 登录与同步

本版保留现有 CloudBase 服务。点击登录时按提示授予服务域名访问权限；拒绝权限仍可使用本机功能。新 ID 已加入现有账号代理的来源白名单，预检通过。用户已确认在自己的电脑实际登录及部分数据同步成功；未说明的数据类别、方向与新增／修改／删除覆盖不计为已验收。账号注册、密码登录、验证码和其他账号是否可用仍取决于服务端规则及各自验证。本版沿用既有来源授权，无需用户填写密钥。

电脑支持用户名、邮箱或手机号配合密码，以及已验证手机号的登录。已有小程序记录时，推荐以下路径：

1. 手机打开美日心灵小程序“设置 → 账号与资料”，确认当前账号，并在“数据与关于 → 数据同步”同步已保存的日程与日课。
2. 电脑插件顶部点“账号”，选择“手机微信授权”，按提示允许服务访问并生成二维码。
3. 手机在小程序“设置 → 账号与资料”的“授权电脑”旁点“扫一扫”，扫描并确认。
4. 电脑显示授权 UID，核对与手机相同后确认登录。已登录同一 UID 时，无需再次扫码。
5. 电脑在账号面板同步日历与日课，按相同日期核对手机记录；再从电脑修改并同步，手机同步后核对内容。可用明确标注的临时日程核对新增、修改和删除，完成后清理。

flomo 在两端分别为当前账号开启；有本机旧笔记时先确认合并范围，原本机记录保留为归档。专注记录与统计也需分别开启：手机位于“数据同步 → 专注记录与统计同步”，电脑位于“专注记录”。这与“把专注加入日程”分别控制，下载的专注记录不重复生成日程块。图片、草稿和进行中的计时留在原设备。可选账号自动同步在前台约每 12 分钟执行，手动同步可立即执行；日程、专注和 flomo 分别查看结果。

1.3.2 保留原始授权码并传递服务端授权范围，支持服务端未签发刷新凭据的会话；确认页显示真实有效期，到期需重新授权，不统一承诺十天免密。该流程需要已部署的设备授权路由；真实终端验收状态见源码的验收记录。

请使用小程序账号页内的扫码按钮；普通微信“扫一扫”不会自动打开此授权流程。编号短时有效，关闭电脑授权窗口或重新生成后应使用新编号。同昵称不表示同账号；其他 UID 的用户名或手机号不会自动打开微信账号的数据。

使用 AI 与 MCP 是另一条独立路径：在小程序“设置 → AI 连接”创建个人连接并配置到 AI 客户端，不要求安装这个插件。当前 AI 可访问已同步的日程、日课、周计划和 flomo 文字与标签，不开放专注历史；AI 改写云端后也需在设备同步接收。

## 常见问题

- 页面未显示：确认选中了含 `manifest.json` 的目录，并检查是否有其他新标签页扩展生效。
- 页面加载不完整：重新加载扩展并新开标签页；保留未保存的输入，查看扩展后台错误。
- 登录显示来源未授权：由维护者追加本版来源；这不是密码错误。本机数据继续保留。
- 导入被拒绝：当前安装已有数据或登录会话，先备份；导入不会覆盖现有内容。

目前以实际验收记录为准；未实测的 Edge、macOS、Linux 不宣称已通过。

## 1.3.3 记录历史

本版安装包为 `inner-garden-1.3.3.zip`，旧版 1.3.2 安装包仍保留。先备份本机内容，覆盖原安装目录并重新加载，保持扩展 ID 和浏览器个人资料，不卸载扩展。Chrome 与 Ego 需要分别重新加载并重新打开新标签页。

配套历史服务已上线。从时间块或日课编辑器进入“历史”；找不到原记录时用日期旁“更多 → 当天变更”。每条保留最近两个不同旧内容，恢复需联网并校验当前版本；未保存草稿保留在本机。小程序需使用支持历史功能的版本，客户端更新与真实跨端操作分别验收。当前验证范围见随包的记录历史说明 `RECORD_HISTORY.md`。
