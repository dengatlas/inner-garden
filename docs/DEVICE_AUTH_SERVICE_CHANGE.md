# 设备授权代理补丁

状态：本地准备并验证，尚未部署。2026-10-01。

目标是现有 CloudBase 环境中的 `tab-out-sync` 函数，仅修改部署包根目录 `auth-proxy.js`。既有密码登录、验证码、刷新、工作区和 flomo 处理保持原样；不修改环境变量、来源白名单、账号绑定或用户数据。

补丁实现见 [device-auth-proxy-patch.mjs](../scripts/device-auth-proxy-patch.mjs)。补丁严格检查四个唯一原文位置，部署源码不同则停止，不盲目覆盖。

具体变化：

1. 允许 `POST /auth/v1/device/code`，仅转发 `client_id`；沿用已有登录请求频率限制。
2. `/auth/v1/token` 除既有 `refresh_token` 外，允许官方 `urn:ietf:params:oauth:grant-type:device_code`；两种凭据不能混用。
3. `grant_type` 长度上限从 32 改为 64，`device_code` 上限 4096；没有扩大请求总大小限制。
4. 保留精确来源验证、超时、请求字段白名单及上游错误码。

使用当前部署源码验证：原账号代理 15 项回归、新设备授权 3 项检查，合计 18/18 通过。新增检查覆盖字段筛选、待确认错误转发、非法/混合授权拒绝、未授权来源拒绝、请求限流。

部署前保存原始代码包供回滚，核对函数代码指纹及设置没有并发变化；重新打包时逐文件比较，仅允许 `auth-proxy.js` 内容不同。部署后回读代码、验证旧来源及新来源，并检查设备编号和待确认轮询。真实手机授权和同步另行验收。
