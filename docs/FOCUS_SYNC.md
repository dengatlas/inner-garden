# 专注记录同步

顶部计时器支持可选任务备注；“专注记录”查看当前账号或访客的今日、周、月统计和明细。完成记录由后台统一写入，多标签页不会重复记账；暂停期间不累计，后台到期按实际结束时刻记录。休息、放弃不计入，首版不提供事后编辑或删除。

在记录面板单独开启账号同步，默认关闭。沿用现有“立即同步”及前台每12分钟检查；关闭后保留缓存。开始计时时固定身份，途中切换账号不会改归属；访客及旧历史需要先确认数量、日期范围再认领，不自动流入另一个账号。相同记录去重，不同设备时间重叠的记录分别累加；统计按上海完成日期从原始明细计算。

原始记录和日程块分别维护，删除日程不扣减专注统计。手机收到电脑记录可以统计，但不会再将该远端记录重复投影成日程。

本版1.3.0需要现有CloudBase工作区后端增加focus_session支持；旧后端未支持时显示提示并保留队列，不影响已有日课／日程。服务账号、网关和合法域名保持原配置。合法域名有修改次数限制，任何修改保存必须先得到用户明确同意。

维护边界：D:/tab-out的shared/focus-records.js与workspace-sync.js是来源，通过scripts/sync-focus-contract.mjs清单同步，docs/focus-contract.json记录摘要。同步客户端的专注逻辑分别移植，保留本插件认证实现；不复制整个shared目录。两个仓库分别提交，先准备现有后端的新集合/索引及兼容代码，再更新客户端。源码、安装包、本地Chrome验证、现网和真机验收分别记录。
