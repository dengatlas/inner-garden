# Inner Garden · 美日心灵 1.3.3

日程与日课现在可查看最近两个不同旧内容，比较差异后恢复为新版本。日期旁“更多 → 当天变更”可查找移到其他日期或已删除的记录。恢复会校验当前版本，保留本机未保存草稿；跨端同步使用明确删除和独立设备身份，保护独立新增及已有重试请求。

## 安装与更新

下载附件 `inner-garden-1.3.3.zip`，可用同名 `.sha256` 文件核对。GitHub 自动生成的 Source code 是源码包。

- 首次安装：解压 ZIP，在 `chrome://extensions` 启用开发者模式，加载包含 `manifest.json` 的目录。
- 已装公开版：先备份，将新版覆盖到原安装目录，点击扩展“重新加载”并重新打开新标签页。保持同一扩展 ID 和浏览器个人资料，不要卸载。Chrome 与 Ego 分别更新。
- GitHub 下载版需手动更新；1.3.2 发布附件继续保留。
